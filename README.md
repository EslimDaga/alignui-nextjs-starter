# AlignUI Next.js Starter

A starter template built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and a full set of [AlignUI](https://alignui.com) components ready to use.

## Tech Stack

- [Next.js 16](https://nextjs.org) — App Router + Turbopack
- [React 19](https://react.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Radix UI](https://www.radix-ui.com) primitives
- [tailwind-variants](https://www.tailwind-variants.org) for component styling
- [Phosphor Icons](https://phosphoricons.com)
- TypeScript

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Scripts

| Command         | Description                  |
| --------------- | ---------------------------- |
| `npm run dev`   | Start the dev server         |
| `npm run build` | Build for production         |
| `npm run start` | Run the production build     |
| `npm run lint`  | Run ESLint                   |

## Project Structure

```
src/
├── app/          # Next.js App Router routes
├── components/
│   └── ui/       # AlignUI components
├── hooks/        # Reusable hooks (use-notification, use-tab-observer)
└── utils/        # Helpers (cn, tv, polymorphic, recursive-clone-children)
```
